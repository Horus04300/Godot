# 불씨의 성소 (Ember Sanctuary)

Godot 4.5.1로 만든 Windows용 탑다운 도트 액션 로그라이트 데모입니다.
제공된 세 영상의 화면을 로컬에서 확인하여 **스크롤 탐험, 유물 가방, 소형 HUD, 이동과 베기를 연결하는 전투**로 개편했습니다.
캐릭터, 적, 타일, 이펙트, 효과음은 이 프로젝트에서 직접 생성하며 원작 리소스를 사용하지 않습니다.

## 영상에서 반영한 방향

관찰 구간은 참고 영상의 재생 시간이며 원작 내부 수치나 소스 코드를 분석한 결과가 아닙니다.
회피 충전량, 공격 선딜, 가방 인접 보너스와 상점 가격은 이 데모에서 직접 설계한 규칙입니다.
영상 프레임, 로고, 캐릭터, 원작 UI 이미지, 음원을 게임이나 배포 ZIP에 넣지 않았습니다.

## 실행

- **`start_game.cmd`를 더블클릭**하거나 `build\EmberSanctuary.exe`를 실행하세요.
- 별도의 Godot 설치나 인터넷 연결 없이 실행됩니다.
- 실행 파일과 같은 위치의 `EmberSanctuary.pck`는 함께 보관해야 합니다.
- 배포용 단일 EXE와 배포 ZIP은 `build\release\EmberSanctuary.exe` 및 `build\EmberSanctuary-Windows-x64.zip`입니다. 배포용 EXE에는 게임 데이터가 포함되어 별도 PCK가 필요 없습니다.
- Windows 64비트, OpenGL 3.3 호환 그래픽 환경이 필요합니다.
- 기본 창 크기는 1280×720, 최소 크기는 960×540입니다. 화면 비율을 유지합니다.
- 키보드와 마우스용 데모입니다. 게임패드와 모바일 터치 조작은 제공하지 않습니다.

## 플레이 흐름

1. 야영지에서 **성소에 들어가기**를 선택합니다.
2. 적의 붉은 공격 예고를 보고 회피하면서 방 안의 적을 처치합니다.
3. 유물 세 개 중 하나를 선택합니다. 같은 유물은 중첩됩니다.
4. 열린 **서쪽 문(E)**은 일반 전투, **동쪽 문(E)**은 강화 전투로 이어집니다. **북쪽 경로판(E)**에서는 다음 경로를 메뉴로 선택할 수 있습니다.
5. 네 번째 방은 서쪽 문으로 휴식, 동쪽 문으로 보물방에 갑니다. 북쪽 경로판에서는 **휴식·보물·금화 상점** 중 선택합니다.
6. 일곱 번째 방에서 수호자를 처치하면 데모가 끝납니다.
7. 사망, 야영지 귀환, 창 닫기 시 모은 불씨를 정산합니다. 불씨로 다음 탐험의 시작 능력치를 강화하세요.

전투 방에 적이 추가 생성되지는 않습니다. 방에 남은 적을 모두 처치하면 보상을 받습니다.
카메라가 플레이어를 따라가므로 방 전체가 한 화면에 보이지 않습니다. 구석의 적과 출구는 미니맵을 보며 찾으세요.
아직 반응하지 않은 먼 적은 미니맵에 표시되지 않습니다. 가까이 가면 추격을 시작합니다.
강화 전투는 적 체력과 처치 불씨가 증가하며, 보상 선택 시 체력을 12 회복합니다.
처치 시 생성되는 작은 불씨는 각각 체력을 1 회복합니다. 영구 강화용 불씨는 적 처치 순간 이미 적립됩니다.
나무 상자와 항아리는 검이나 광역 기술로 파괴할 수 있고, 각각 금화 3을 즉시 얻습니다.
금화와 경험치·레벨은 이번 탐험 동안만 유지됩니다. 레벨업하면 최대 체력 +5, 공격력 +2, 체력 15 회복을 얻습니다.

## 조작

| 기능 | 입력 |
|---|---|
| 이동 | WASD 또는 방향키 |
| 조준 | 마우스 |
| 기본 베기 | 좌클릭 유지 또는 J 유지 |
| 불씨 폭발 | 우클릭 또는 Q / K |
| 회피 | Space, 이동 방향으로 회피하며 짧은 무적. 최대 2회 충전 |
| 회복약 | F |
| 문, 유물 상자, 샘, 상인 상호작용 | 가까이에서 E |
| 유물 빠른 선택 | 1 / 2 / 3 |
| 일시정지, 메뉴 뒤로 | Esc |
| 조작 수첩 | 전투 중 Tab |
| 유물 가방 | I, 다시 누르거나 Esc로 탐험 복귀 |
| 탐험 지도 | G, 다시 누르거나 Esc로 탐험 복귀 |
| 화면 흔들림·섬광 켜기/끄기 | V |
| 조준 방식 변경 | T, 마우스 조준 ↔ 이동 방향 조준 |
| 음소거 | M |
| 사망 또는 승리 후 즉시 재도전 | R |
| 메뉴 조작 | 마우스 또는 Tab / Shift+Tab, Enter / Space |

**키보드만 사용할 때는 T로 이동 방향 조준을 켜세요.**
이동 방향이 마지막 공격 방향으로 유지됩니다. 세 번째 연격은 기본 피해의 1.6배이며,
불씨 폭발은 주변 전체에 기본 피해의 2.4배를 줍니다.
기본 베기의 타격은 입력 후 0.045초, 폭발은 0.07초 뒤에 발생합니다. 선딜 중 회피하면 아직 발생하지 않은 타격은 취소됩니다.
회피 중 기본 공격은 사거리 +22, 피해 +25%의 돌진 베기입니다.
회피는 기본 1초마다 하나씩 충전되며 최대 2개를 보관합니다. HUD의 두 표시로 확인하세요.
넉백으로 적을 벽이나 기둥에 부딪히게 하면 해당 넉백당 추가 피해 10을 줍니다.
피격·타격 정지·사거리의 기준 위치는 각 캐릭터의 발밑입니다.
회복약과 회피, 기술에는 각각 잔량 또는 재사용 시간이 표시됩니다.
전투는 보상 선택, 경로 선택, 가방, 지도, 상점, 수첩, 일시정지 상태에서 멈춥니다.
보상 선택 중 Esc를 누르면 보상을 중앙 제단에 남깁니다. 제단에서 E로 같은 선택지를 다시 열 수 있습니다.

## 유물 가방과 금화

- 가방은 **5열×4행**입니다. 같은 유물은 새 칸을 쓰지 않고 중첩됩니다.
- I로 가방을 열고 유물이 든 칸을 선택한 다음, 빈 칸 또는 다른 유물을 선택하면 이동하거나 맞바꿉니다.
- 같은 칸을 다시 누르면 이동 선택을 취소합니다. 드래그 조작은 제공하지 않습니다.
- 공격 계열, 생존 계열, 기동 계열을 테두리로 구분합니다. 이름·설명과 아래 계열 목록으로도 확인할 수 있습니다.
- **같은 계열이 상하좌우로 맞닿은 연결마다 공격력 +2**입니다. 대각선 연결은 계산하지 않고, 중첩 수가 연결 수를 늘리지는 않습니다.
- 공격 계열: 숫돌, 심지, 방울, 그림자, 왕관, 깃털. 생존 계열: 심장, 송곳니, 갑옷, 병. 기동 계열: 장화, 렌즈.
- 연결 공격력은 기본 베기와 광역 기술 모두에 반영되며, 배치를 바꾸면 즉시 다시 계산합니다.
- 보상 선택은 방마다 **무료 다시 보기 1회**가 있습니다. 다시 본 세 유물은 직전 선택지와 겹치지 않습니다.
- 상점의 유물은 **금화 25**, 회복과 회복약 보충은 **금화 12**입니다. 유물 구매는 해당 방에서 한 번만 가능합니다.

## 포함된 콘텐츠

- 큰 방을 추적하는 카메라, 현재 방 미니맵과 일곱 방 진행 지도
- 물리적인 좌우 출구 및 경로 메뉴, 휴식·보물·금화 상점 분기
- 세 가지 일반 적: 추격형, 원거리형, 중장형
- 강화 적, 네 가지 폐허 벽·기둥 배치, 장애물을 우회하는 격자 경로 탐색
- 검으로 파괴하는 상자·항아리, 금화, 처치 경험치와 레벨업
- 원형 탄막, 조준 산탄, 지면 폭발을 사용하는 보스 및 체력 절반 이하의 강화 패턴
- 공격력, 최대 체력, 화상, 흡혈, 전이, 이동, 기술 재사용, 사거리, 치명타, 반격, 회복약, 공격 속도 유물 12종
- 휴식 제단, 유물 보물방, 유물 선택·다시 보기, 배치를 변경하는 20칸 가방
- 회복약, 피격 무적, 2회 회피와 돌진 베기, 넉백·벽 충돌, 피해 숫자, 타격 정지, 잔상·충격 파편·전이선
- 5단계 영구 강화: 단계당 시작 체력 +12, 공격력 +2
- 한국어 UI, 키보드 메뉴 탐색, 음소거, 절차 생성 효과음
- 로컬 저장과 저장 실패 안내

현재 범위는 전투 루프를 체험하는 데모입니다.
장비 교체, 직업 선택, 복수 층의 절차적 연결 맵, 퀘스트, 대사, 온라인 플레이, 배경 음악은 포함하지 않습니다.
현재 지형은 네 가지 수제 배치이며, 지도는 실제로 선택한 방의 순서를 보여 줍니다. 미지의 거대한 던전을 생성하는 시스템은 아닙니다.
아트는 직접 만든 픽셀 스프라이트·타일·아이콘과 프로그램으로 그리는 도형으로 구성되어 있습니다.

## 저장

Godot 사용자 데이터 폴더의 `sanctuary_save.json`에 보유 불씨, 영구 강화 단계, 최고 진행도를 저장합니다.
Windows 기본 위치는 `%APPDATA%\Godot\app_userdata\` 아래의 게임 이름 폴더입니다.
현재 탐험의 유물과 방 상태는 저장하지 않으므로 종료 후에는 야영지에서 시작합니다.
정상 종료 시 진행 중이던 탐험의 불씨는 정산됩니다. 강제 종료나 전원 차단 직전의 불씨는 보장하지 않습니다.

임시 파일에 쓰고 교체하는 방식으로 저장합니다.
잘못된 형식의 기존 저장은 자동으로 덮어쓰지 않으며 화면에 오류를 표시합니다.
저장 오류가 있을 때는 영구 강화 구매를 막고, 메모리 안에서만 탐험을 계속할 수 있습니다.
오류 발생 시 게임을 닫고 기존 파일을 백업한 다음 파일 권한과 내용을 확인하세요.

## Godot에서 수정

- `open_editor.cmd`로 함께 제공한 Godot 편집기를 열 수 있습니다.
- 편집용 실행기는 `runtime`에, 개발 실행용 게임은 `build`에, 배포용 단일 EXE는 `build\release`에 있습니다.
- 또는 설치한 **Godot 4.5.1 이상**에서 `project.godot`를 가져오세요.
- 편집기에서 F6 또는 F5로 소스 프로젝트를 실행합니다.
- `scripts\game.gd`: 전투, 방 진행, 보상, 메뉴, 저장
- `scripts\pixel_art.gd`: 픽셀 스프라이트와 타일 팔레트
- `scripts\sound.gd`: 짧은 효과음 합성 및 재생
- `tests\integration.gd`: 실제 뷰포트 마우스·키보드 입력과 저장 왕복 테스트
- `main.tscn`: 시작 씬
- `export_presets.cfg`: 개발용 리소스 팩과 배포용 Windows 프리셋

개발용 편집기는 `runtime`에 동봉되어 있습니다. 편집기에서 편리하게 수정할 수 있지만, 최종 배포에는 별도의 최적화된 Godot 릴리스 템플릿을 사용합니다.
`Windows Release`를 내보내려면 해당 컴퓨터에 동일한 Godot 버전의 공식 Windows export template이 설치되어 있어야 합니다.
아래 명령은 자동 코드 서명하지 않으며, 내보낸 EXE를 사용자가 최종 실행 전에 시험할 책임이 있습니다.

```powershell
# 프로젝트 폴더에서 실행
& '.\runtime\Godot_v4.5.1-stable_win64.exe' --headless --editor --path '.' --export-pack 'Windows Desktop' '.\build\EmberSanctuary.pck' | Out-Host

# 최종 배포용 단일 EXE 재생성
& '.\runtime\Godot_v4.5.1-stable_win64.exe' --headless --path '.' --export-release 'Windows Release' '.\build\release\EmberSanctuary.exe' | Out-Host

# EXE 및 배포 고지를 ZIP으로 묶기
Compress-Archive -Path '.\build\release\EmberSanctuary.exe','.\build\release\README.txt','.\build\release\GODOT_LICENSE.txt','.\build\release\GODOT_COPYRIGHT.txt' -DestinationPath '.\build\EmberSanctuary-Windows-x64.zip' -CompressionLevel Optimal -Force

# 소스 프로젝트의 전투 로직 테스트
& '.\runtime\Godot_v4.5.1-stable_win64.exe' --headless --path '.' --quit-after 1200 -- --self-test | Out-Host

# 실제 메뉴 클릭/키 입력, 방 진행, 저장 파일 왕복 테스트
& '.\runtime\Godot_v4.5.1-stable_win64.exe' --headless --path '.' --quit-after 1200 -- --ui-test | Out-Host

# 가방 이동·연결 보너스·상점·출구·회피 연계·벽 충돌 회귀 검사
& '.\runtime\Godot_v4.5.1-stable_win64.exe' --headless --path '.' --quit-after 1800 -- --overhaul-test | Out-Host

# 강제 적 처치 없이 실제 이동·공격·회피·피격·회복으로 일곱 방 클리어
& '.\runtime\Godot_v4.5.1-stable_win64.exe' --headless --path '.' --quit-after 1800 -- --combat-test | Out-Host
```

테스트는 일반 저장과 분리됩니다. 저장 테스트용 파일은 생성, 재읽기, 교체를 검증한 후 삭제합니다.
성공 로그는 각각 `SELF_TEST_PASS`, `INTEGRATION_PASS`, 마지막 `OVERHAUL_PASS`, `COMBAT_RUN_PASS`입니다. 성공 로그 없이 종료되거나 assertion·스크립트 오류가 있으면 실패입니다.
Godot 릴리스 템플릿은 `assert`를 제거할 수 있으므로 논리 검증은 편집기 실행기로 먼저 수행합니다. 배포 EXE에서는 동일 시나리오의 완료 로그, 런타임 오류, 실제 화면 시작을 별도로 확인합니다.
`--capture=절대경로.png`와 `--capture-scene=hub|reward|boss|inventory|action`은 화면 검토용입니다.
`action`은 공격 연출 검토를 위해 적 배치와 타격 순간을 통제하는 장면이며, 자연 플레이의 성과를 보여 주는 영상이 아닙니다.

## 시각 방향과 이유

- **ENERGY 3 / RHYTHM 2 / MOTION 3**: 액션의 타격감은 강하게, 전투 정보 위치는 일관되게 유지합니다.
- 회청색 석재·이끼와 황갈색 목재는 폐허를 표현하며, 밝은 망토·청록 기술·금빛 보상으로 배경과 대상을 분리합니다.
- 붉은 예고는 적의 위험 정보에 사용합니다. 위험은 색뿐 아니라 선, 원, 팽창하는 지면 표시로도 전달합니다.
- 좌상단 체력·경험치, 우상단 미니맵, 좌하단 기술, 우하단 재화는 중앙을 전투 공간으로 비워 두기 위한 배치입니다.
- Windows 맑은 고딕을 시스템 글꼴로 사용해 한국어 메뉴를 읽기 쉽게 합니다. 글꼴 파일은 배포하지 않습니다.
- 각진 가방 칸과 계열 테두리는 픽셀 아트와 배치 규칙에 맞추고, 중앙 성소 문양과 미니맵으로 방향을 안내합니다.
- 애니메이션은 타격, 예고, 회피, 회복, 출구 상태를 전달합니다. V로 화면 흔들림과 섬광만 끌 수 있고 위험 예고는 유지됩니다.
- 어두운 성소 배경은 밝은 칼 궤적과 위험 예고를 식별하기 위한 고정 게임 팔레트입니다.

## 검증

Godot 파서, 전투 로직, 실제 뷰포트 입력 통합 테스트와 개편 회귀 테스트를 실행했습니다.
UI 전환 테스트에서는 적 체력을 0으로 만들어 상태 전환을 통제하고, **별도 연속 전투 테스트는 강제 적 처치 없이** 실제 피해·재사용 시간·회복약으로 일곱 방을 진행해 보스를 처치합니다.
이 자동 플레이는 경로와 전투의 완주 가능성을 확인하는 것이며, 사람의 플레이 감각이나 다양한 빌드의 난이도 밸런스를 보증하지는 않습니다.

실제 입력 검증 항목:

- 야영지 안내 클릭 → 수첩 표시 → Esc → 야영지
- 입장 클릭 → 전투 → Esc → 일시정지
- 음소거 클릭 → 소리 꺼짐 → 유물 목록 → 조작법 → 뒤로 → 계속
- T → 키보드 조준, Tab → 수첩, Esc → 전투 복귀
- 세 유물 선택 버튼 → 획득·중첩 → 열린 출구
- 일반·강화·휴식·보스 경로 및 경로 취소 → 해당 방 또는 이전 방
- 승리 재도전, 사망 귀환, R 재도전, 중도 귀환 → 정상 상태 전환
- 영구 강화 구매 → 불씨 차감 → 다음 탐험 능력치 반영
- 휴식의 회복과 공격력 축복 → 각 효과 적용
- 화상·흡혈·전이·반격 → 실제 피해 및 회복, 기술 재사용 중 재발동 차단
- 치명적인 투사체·지면 폭발 → 사망 화면, 배열 접근 오류 없음
- 저장 → 재읽기 → 교체 저장 → 재읽기 → 수치 일치
- I → 가방 → 유물 칸·빈 칸 실제 클릭 → 이동 및 연결 보너스 재계산
- G → 지도 → 계속, V → 화면 효과 감소
- 다시 보기 → 새 선택지·횟수 제한, Esc → 제단에 보상 보류 → E → 같은 선택지 복원
- 서쪽·동쪽 문 → 실제 일반·강화 방 진입
- 상점 회복·유물 구매 → 금화 차감·효과·중복 구매 제한
- 선딜 중 피해 없음 → 타격 시점에 피해, 회피 취소·돌진 베기·충전 회복
- 큰 이동량에도 벽 관통 없음, 벽 우회 경로·넉백 벽 충돌 피해 확인

### 디자인 전달 게이트

- **Hard Gate PASS**: 한국어 메뉴와 동작하는 버튼, 키보드 탐색·닫기, 실제 입력 통합 검증. 체력 수치 배경을 보정하고 주요 UI 텍스트의 대비를 4.5:1 이상으로 측정했습니다. 저장 오류와 빈 유물 목록 상태 제공. 네트워크 로딩·웹 내비게이션·모바일·테마 전환은 없는 데스크톱 게임입니다.
- **Purpose Gate PASS**: 세 영상의 관찰 구간과 적용 항목, 색상·서체·구조·이펙트의 목적을 기록했습니다. 도트 타일은 성소의 바닥이고 선·원은 전투 예고입니다.
- **Liveliness PASS**: 세 방향값을 명시하고 금빛 불씨, 중앙 성소 문양, 전투 시 타격 궤적을 반복 모티프로 적용했습니다.
- **Craftsmanship PASS**: 960×540·1280×720 렌더링, 보상·가방·보스 화면, 실제 입력·저장·신규 전투 규칙과 연속 전투 완주를 검증했습니다. 원작 리소스는 사용하지 않았습니다.
